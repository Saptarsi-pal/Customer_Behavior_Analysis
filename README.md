# Customer_Behavior_Analysis
Data analysis project showcasing customer behavior analysis using Python , SQL and Power Bi.



Customer Behavior Analysis Project
Overview

This project focuses on analyzing customer behavior data to uncover useful business insights. The workflow includes data loading, exploratory data analysis (EDA), data cleaning, SQL-based analysis in MySQL, interactive dashboard creation in Power BI, and final presentation/report generation.

The main objective of this project is to transform raw customer data into meaningful insights that can support better business decisions.

Dataset

The dataset contains customer-related information such as:

Customer ID
Age
Gender
Purchase History
Product Category
Payment Method
Purchase Amount
Frequency of Purchase
Location

This data was used to understand customer purchasing patterns and preferences.

Tools & Technologies
Python – Data loading, cleaning, EDA
Pandas – Data manipulation
NumPy – Numerical operations
Matplotlib / Seaborn – Data visualization
MySQL – SQL queries and database analysis
Microsoft Power BI – Interactive dashboard creation
Gamma – Presentation (PPT) creation
Jupyter Notebook – Development environment
Project Steps
1. Data Loading
Imported dataset using Python
Checked structure, rows, columns, and data types
2. Exploratory Data Analysis (EDA)
Summary statistics
Missing value analysis
Distribution analysis
Correlation checks
Customer trend identification
3. Data Cleaning
Removed duplicates
Handled missing/null values
Corrected inconsistent values
Standardized column formats
4. SQL Analysis in MySQL

Performed SQL queries such as:

Total customers count
Average purchase amount
Top product categories
Gender-wise spending analysis
High-value customers
Repeat customer trends
5. Dashboard Building

Created an interactive Power BI dashboard with:

KPI cards
Sales trends
Customer segmentation
Category performance
Filters & slicers
6. Report & Presentation
Final business report prepared
PPT created using Gamma for project presentation
